
| Type     | Purpose             |
| -------- | ------------------- |
| feat     | New feature         |
| fix      | Bug fix             |
| docs     | Documentation       |
| refactor | Code improvement    |
| test     | Tests               |
| ci       | CI/CD               |
| build    | Build configuration |
| chore    | Maintenance         |
| perf     | Performance         |
| revert   | Revert              |

Example:

feat(auth): add GitHub login

fix(ci): resolve Playwright failure

docs: update architecture overview

refactor(prompt): simplify prompt builder
